# SOStituto junior

Versione per la scuola primaria di [SOStituto](https://github.com/AAPetralia/SOStituto): gestione delle sostituzioni dei docenti per un singolo plesso con un solo referente.

App web in un solo file HTML (`index.html`), senza installazione. I dati (orario, assenze, registro) restano nel browser di chi la usa; il repository non contiene dati di nessuna scuola.

**Stato:** in costruzione. Il punto di partenza è una copia di SOStituto (v16.10.2026d); si procede a snellirla e ad adattare la lettura dell'orario, che nella primaria è per classe.

La versione si legge in alto nell'app, sotto il titolo, ed è registrata in `CHANGELOG.md`.
